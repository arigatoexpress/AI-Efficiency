# Process Improvement Prompts

## Process Map From Notes

```text
Act as a process improvement facilitator.

Current process notes:
[Paste non-sensitive notes.]

Create:
- Current process steps
- Pain points
- Duplicate work
- Wait states
- Failure points
- Suggested improvements
- Metrics to track

Do not assume missing steps. Mark them as questions.
```

## Root Cause Brainstorm

```text
Help me think through root causes.

Problem:
[Describe problem without sensitive data.]

Observed facts:
[List facts.]

Return:
- Likely causes
- Evidence needed for each cause
- Quick checks
- Longer-term fixes
- Risks of acting too soon

Do not pick one root cause unless the facts clearly support it.
```

## Pilot Design

```text
Design a small AI pilot for this operations problem.

Problem:
[Describe problem.]

Users:
[Describe roles.]

Data available:
[Describe data type, not sensitive values.]

Return:
- Pilot goal
- Users
- Inputs
- Output
- Human review step
- Success metrics
- Data risks
- What governance should review
- 2-week test plan
```

## Standard Work Draft

```text
Turn these process notes into a standard work draft.

Notes:
[Paste scrubbed notes.]

Return:
- Purpose
- Scope
- Step-by-step procedure
- Quality checks
- Escalation triggers
- Common mistakes
- Training notes

Keep language simple enough for a new manager to use.
```
