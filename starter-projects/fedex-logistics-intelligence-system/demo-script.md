# Demo Script

Use this when showing the prototype to managers, IT, AI governance, or senior
leaders.

## Opening

```text
This is a public-data decision-support prototype for station operations
managers. It does not use FedEx internal package, customer, employee, route, or
facility data. The goal is to show how AI can help managers notice external
risk faster and draft better human-reviewed updates.
```

## What To Show

1. Open the Cloud Run demo.
2. Show the prototype-only framing.
3. Show a public weather or road-risk card.
4. Show the source trail.
5. Generate a manager-ready shift brief.
6. Point out the "needs internal verification" fields.
7. Explain what would be required before any real pilot.

## What To Say

```text
The app is not making dispatch decisions. It is helping a manager organize
public context and prepare better questions for the approved internal systems
and human owners.
```

## Safe Scenario

Use a synthetic scenario:

```text
Public weather sources show high winds near Gunnison. The app drafts a short
pre-shift huddle note and a verification checklist. A human manager then checks
approved internal systems and local leadership before making any decision.
```

## Questions To Ask Reviewers

- Which public data sources are acceptable for a manager-facing pilot?
- Which internal systems would be the source of truth if this became real?
- What access control would be required?
- Can this be piloted as a read-only briefing tool?
- What should be logged for review?
- Who owns the content if managers submit notes or screenshots?

## Clear Non-Claims

- This is not official policy.
- This is not a production operations system.
- This does not route packages.
- This does not use confidential FedEx data.
- This does not replace manager judgment.
- AI output is a draft until reviewed by a human owner.

## Strong Close

```text
The opportunity is not to automate judgment. The opportunity is to reduce the
time managers spend gathering context, writing updates, and translating public
risk into clear handoffs.
```
