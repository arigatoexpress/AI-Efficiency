## Decision Requested Today

Ask leaders to approve one small, reversible next step:

- nominate one low-risk pilot owner and backup owner;
- approve a 30-day prompt intake for manager workflows;
- keep internal data out until the project review checklist is complete.

## What To Show

1. **README:** frame the repo as a public-safe enablement hub.
2. **Prompt library:** show manager value with copy-paste prompts.
3. **Logistics prototype:** show one public-data station scenario and one draft
   brief.
4. **Governance:** show the checklist and pilot template.
5. **Decision:** open the pilot shortlist and ask for one owner.

## What To Say If Challenged

**Is this official FedEx software?**

No. It is a regional enablement hub and public-data prototype package, not an
official production system or policy.

**Can we use internal data?**

Not from this public repo. Internal-data pilots need an approved environment,
named owners, access controls, retention rules, and governance approval.

**What keeps this safe?**

Public or synthetic data first, human review on every output, source labels,
documented stop conditions, and no automatic external sends.
