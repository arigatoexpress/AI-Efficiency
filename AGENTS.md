# AI Efficiency Team Agent Notes

This repository is a public-safe documentation and starter-project hub for an
operations-led AI efficiency team.

## Boundaries

- Keep the repo safe for public or governance review.
- Do not add secrets, credentials, customer data, package data, employee data,
  route manifests, security-sensitive material, or proprietary FedEx internal
  data.
- Do not copy private source projects into this repository unless Ari explicitly
  confirms the target visibility and sharing scope.
- Do not claim a project is production-ready unless it has live verification,
  documented owners, approved data handling, and governance signoff.
- Preserve clear language around prototypes, paper-only demos, synthetic data,
  and human review.

## Documentation Style

- Write for non-technical operations managers first.
- Use plain English, short sections, and copyable examples.
- Include practical "when to use / when not to use" guidance.
- Prefer checklists and templates over abstract policy language.
- Keep citations to official technology docs when describing vendor features.

## Safe Defaults

- If a project involves FedEx data, assume it needs privacy, security, legal,
  and AI-governance review.
- If a prompt could influence a real operational decision, require a human
  verification step.
- If a workflow sends messages externally, require explicit human approval
  before sending.
